# AI Usage

This project was built with mindful use of an AI assistant (Claude, by Anthropic),
as permitted by the assessment brief. This document records where it was used,
what I did with its output, and what I wrote myself.

## Principles I followed

- AI was used for guidance, drafts and troubleshooting, not to generate the whole application.
- I reviewed every piece of AI-assisted output before using it, and I can explain it.
- Architecture decisions, application code, tests and documentation are my own work,
  except where listed below.

## Log

| Area | How AI was used | What I did |
|------|-----------------|------------|
| Planning | Discussed the assessment requirements, phased approach and checklist | Chose the stack and the order of implementation |
| Database schema (`db/schema.sql`) | Claude drafted the initial SQL schema and seed script from the hints document | Reviewed every table, constraint and index. Decisions I made: foreign keys use RESTRICT (NO ACTION), `UserRoles` join table replaces `Users.RoleId` for the many-to-many requirement, `AlertRules` table added. Users are seeded by the application, not SQL. |
| Environment setup | Help with the Docker Compose file for SQL Server, solution/project structure commands, and Git/GitHub setup | Ran and verified each step on my machine |
| Dependency warning (NU1903) | Explained the Microsoft.OpenApi advisory (GHSA-v5pm-xwqc-g5wc) | Pinned `Microsoft.OpenApi` 2.7.5 in `WebAPI.csproj` |
